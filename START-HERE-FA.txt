جارویس 1.0.0 — پروژه جداگانه از ماریا
===================================

اجرای فوری در ویندوز (با Python 3):
  1) فایل ZIP را Extract کن.
  2) فایل run_jarvis_windows.bat را دوبار کلیک کن.
  3) صفحه http://127.0.0.1:8800 باز می‌شود.

برای فعال شدن صدای طبیعی فارسی:
  py -3 -m pip install edge-tts

برای ساخت EXE در ویندوز:
  روی فولدر Jarvis راست‌کلیک → Open in Terminal
  .\build_windows.ps1
  خروجی: dist\Jarvis.exe
  اگر NSIS نصب باشد: dist\Jarvis-Setup-1.0.0.exe
